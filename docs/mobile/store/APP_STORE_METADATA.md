## Description

MealScout is a local food operations and discovery app built for real-world daily use.

Use MealScout to:

- Find local food deals and events
- Check what is active now on the map
- View menus and place pickup orders
- Follow favorite local businesses

Business operators can also:

- Manage schedules and live location updates
- Coordinate event participation workflows
- Keep social updates aligned with operating activity
- Track analytics and operational outcomes

MealScout combines discovery, booking workflows, and operational visibility in one place so teams can move faster with less manual work.
