# Store Assets Checklist

Mark each item complete before submitting to TestFlight or Play internal testing.

- [ ] App icon source file and exported platform sizes
- [ ] Launch/splash assets for iOS and Android
- [ ] iPhone screenshots (required sizes)
- [ ] iPad screenshots (if iPad support enabled)
- [ ] Android phone screenshots
- [ ] Android 7-inch/10-inch screenshots (if required)
- [ ] Feature graphic (Play Store)
- [ ] Optional promo video link (Play Store)
- [ ] Privacy policy URL published and accessible
- [ ] Support contact email validated
